Slide 1: Problem & Mission

The Ops Person Small Businesses Can't Afford

The Operational Burden:
Small business owners spend 30-50% of their time on admin - tracking finances, managing inventory, making routine decisions. No dedicated ops staff, no analytics tools at their scale, no time to learn enterprise software like Shopify or Square.

The Navigare Solution:
Navigare automates the analytics that would otherwise require hiring a dedicated ops person. One dashboard: inventory health, sales forecast, customer segments, SEO audit, market basket - all in one place. Upload two CSVs and get actionable insights in seconds.

Inspired by a Streamlit prototype (src/dashboard.py) that proved the concept worked but lacked production readiness, user authentication, and a polished UI.

Slide 4: Deployment Journey

From Code to Live Website

Architecture: Designed Vercel -> Render -> Supabase stack. Free-tier deployment at zero cost.
Development: Built 11 pages, 8 API endpoints, auth system. Full CRUD flow from upload to dashboard.
Testing: Local testing with uvicorn + next dev, Playwright screenshots. All endpoints verified via curl + tsc --noEmit.
Deployment: Pushed to GitHub -> auto-deploy to Render + Vercel. Live at navigare-one.vercel.app.

Key challenge: Render Docker build failed because Dockerfile had "COPY .env ." but .env is gitignored. Fix: removed the line, moved all config to Render environment variables. Also required manual redeploy trigger.

Slide 7: What We Learned

Engineering Lessons

Docker: Builds fail silently when gitignored files are referenced in Dockerfile. Always test docker build locally. python-dotenv does not work in containers - use env vars exclusively.

Design: "DEMO DATA" watermark essential - users can't tell if data is real or sample without a persistent banner on every page.

Deployment: Auto-deploy requires active (non-suspended) services. Persistent background processes prevent crashes between sessions.

Collaboration: Git worktrees enable clean parallel feature development with consistent .gitignore fixes synced across branches.
